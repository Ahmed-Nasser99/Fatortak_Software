The architectureالبنية

One ledger behind every module. دفتر واحد خلف كل وحدة.

An invoice is not a document with a total. It posts a receivable, revenue and VAT. A payment clears the receivable. A cheque is not cash until it clears. The reports read the same postings, so the trial balance, P&L and project margin cannot quietly disagree. الفاتورة ليست مستنداً يحمل رقماً. هي تُنشئ مديناً وإيراداً وضريبة. الدفعة تسدد المدين، والشيك ليس نقداً حتى يُحصَّل. التقارير تقرأ نفس القيود، فلا يمكن أن يختلف ميزان المراجعة وقائمة الدخل وربحية المشروع في صمت.

  • Every financial event posts a balanced journal entry.كل عملية مالية تُنشئ قيداً متوازناً.
  • Unlinked project costs are shown as unallocated, not hidden.التكاليف غير المرتبطة بالمشروع تظهر كغير مخصّصة، ولا تُخفى.
  • Manual journal entries stay possible for the accountant.يبقى القيد اليدوي متاحاً للمحاسب.

Is Fatortak really free?هل «فاتورتك» مجانية فعلاً؟

Yes. The community edition is free forever under AGPL-3.0 and includes invoicing, double-entry accounting, projects, inventory, HR and payroll. You pay for managed cloud, migration, support or a commercial license.نعم. النسخة المجتمعية مجانية للأبد بترخيص AGPL-3.0 وتشمل الفواتير والمحاسبة بالقيد المزدوج والمشروعات والمخزون والموارد البشرية والرواتب. المدفوع هو السحابة المُدارة والترحيل والدعم أو الترخيص التجاري.

Does it support Arabic and RTL properly?هل تدعم العربية وRTL فعلاً؟

Yes: full RTL layouts, Arabic invoices, Arabic PDF fonts and a bilingual UI. Arabic is a primary requirement, not a translation layer. Native Arabic review is ongoing.نعم: واجهات RTL كاملة وفواتير عربية وخطوط PDF عربية وواجهة ثنائية اللغة. العربية متطلب أساسي وليست طبقة ترجمة. والمراجعة العربية مستمرة.

Does it handle Egypt ETA or Saudi ZATCA e-invoicing?هل تدعم الفاتورة الإلكترونية المصرية أو زاتكا السعودية؟

Not yet. ETA and ZATCA clearance are not implemented. We will not claim compliance we do not have. It is on the roadmap; if it is a hard requirement today, use a compliant provider for that function until the integration ships.ليس بعد. لا يوجد تكامل مع ETA أو ZATCA، ولن ندّعي امتثالاً غير موجود. هو على خارطة الطريق؛ وإذا كان إلزامياً اليوم فاستخدم مزوداً متوافقاً لهذه الوظيفة حتى يصدر التكامل.

Can I self-host it?هل يمكنني استضافته بنفسي؟

Yes. Docker Compose runs the React web app, the .NET 8 API and SQL Server. The self-hosting guide covers HTTPS, backups, configuration and production notes.نعم. يشغّل Docker Compose واجهة React وواجهة .NET 8 API وSQL Server. ويغطي دليل الاستضافة HTTPS والنسخ الاحتياطي والإعداد وملاحظات الإنتاج.

What is the stack?ما التقنيات المستخدمة؟

ASP.NET Core 8, EF Core 8, SQL Server, React 18, TypeScript, Vite, Tailwind CSS and JWT auth. AI is Gemini/OpenRouter for the assistant and OCR; it is optional.ASP.NET Core 8 وEF Core 8 وSQL Server وReact 18 وTypeScript وVite وTailwind CSS ومصادقة JWT. الذكاء الاصطناعي عبر Gemini/OpenRouter للمساعد وOCR، وهو اختياري.

Is it production-ready?هل هي جاهزة للإنتاج؟

It is public alpha. There is no independent security audit yet and test coverage is thin. Start with a pilot behind HTTPS, with a strong JWT key and a restricted database user. Do not expose a fresh instance to the public internet without reading SECURITY.md.هي ألفا عامة. لا يوجد تدقيق أمني مستقل بعد، والتغطية الاختبارية محدودة. ابدأ بتجربة محدودة خلف HTTPS بمفتاح JWT قوي ومستخدم قاعدة بيانات مقيّد. لا تنشر نسخة جديدة على الإنترنت قبل قراءة SECURITY.md.

Can I get a commercial license?هل يمكنني الحصول على ترخيص تجاري؟

Yes. A commercial license is available for companies that cannot accept AGPL-3.0, including closed-source products and hosted services. Email info@fatortak.net for terms.نعم. الترخيص التجاري متاح للشركات التي لا تستطيع الالتزام بـ AGPL-3.0، بما في ذلك المنتجات مغلقة المصدر والخدمات المستضافة. راسل info@fatortak.net للشروط.

Do you help with migration and training?هل تساعدون في الترحيل والتدريب؟

Yes, as a paid service. We import customers, suppliers, opening balances and the chart of accounts, and train the team. Migration is quoted after a short data review, not guessed.نعم، كخدمة مدفوعة. نستورد العملاء والموردين والأرصدة الافتتاحية وشجرة الحسابات، وندرّب الفريق. يُسعَّر الترحيل بعد مراجعة قصيرة للبيانات، لا بالتخمين.
